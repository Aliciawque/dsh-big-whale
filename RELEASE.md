# Release 0.6.0-rc.8

Event poses from merged PR #7 (commit `f48b1e025399af56eddadc32c24519966989aaf7`). This is a prerelease for the npm `next` channel.

The companion holds the rice bowl and dips its head during compaction, smiles and makes a peace sign in the maid outfit on completion, and draws its arms inward with a small sweat drop on failure. Poses appear directly when the corresponding event is received, even with event voice disabled.

Install after registry publication:

```sh
dsh plugin --profile web add dsh-big-whale@0.6.0-rc.8
```

The exact npm archive is tested in an isolated Web-backed DSH profile. See docs/VERIFICATION.md for bounded evidence. Character assets remain CC BY-NC-SA 4.0, code retains MIT notices.
